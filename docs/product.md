# Corelia Web: рабочее место документов

Клиент отображает документы и процессы из API Corelia. Виды, поля, статусы, колонки, поисковые поля и политика вложений приходят из каталога конфигурации заказчика. Сборка клиента не требует изменений для другого набора видов.

Пользователь может найти и создать документ, изменить разрешённые реквизиты, просмотреть версии и вложения, выполнить предложенное процессом действие. Доступность команд приходит из capabilities; обязательные проверки выполняет ядро. Исторические версии доступны только для просмотра.

Конфигурация определяет виды документов, их поля и требования из внешних схем. Специальных форм по видам в продукте нет. Обязательный первый файл определяется политикой вида.

Реестр поддерживает серверную пагинацию, фильтры и сортировку текущей страницы. Главная показывает фактически полученные документы. Очереди задач используют действующие API Corelia. Полный проход на реальном Platform V после миграции ещё требуется.
