# Corelia Web: пользовательское рабочее место

Клиент показывает данные, возвращённые gateway: каталог типов документов,
реестр, карточку, вложения, версии, историю, задачи и workflow
administration. Конкретные поля формы, колонки и attachments policy приходят
из customer configuration через API; UI не должен встраивать customer type,
статус или роль.

Пользователь проходит OIDC-вход, ищет документ, создаёт/редактирует его при
наличии server-provided capability, загружает или читает файл и выполняет
доступное workflow-действие. Версии отображаются только для чтения. Все
проверки доступа, состояния и изменения выполняются backend; скрытая кнопка
не является механизмом авторизации.

Клиент поддерживает PDF/DOCX/XLSX preview и скачивание. Файл для preview
буферизуется в памяти браузера. Формы создают `requestId`, передают
`expectedVersion`/`changeToken` при PATCH и после успешной записи перечитывают
карточку; 409 означает необходимость согласовать данные с актуальным снимком.

Клиент не доказывает готовность конкретного customer BPMN, S3, Keycloak или
production CORS-контура. Эти зависимости проверяются совместно с backend
развёртыванием.
